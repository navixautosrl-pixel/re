Server Dedicat [4 intrebari]
1. Ce este un server dedicat?

Un server dedicat inseamna hardware exclusiv, folosit doar de tine, fara alti clienti pe aceleasi resurse. Este ideal pentru proiecte cu trafic mare sau cerinte speciale.


2. Cum instalez un panou de control?

Te putem ajuta cu instalarea cPanel/Plesk la cerere; contacteaza echipa de suport pentru asistenta.


3. Pot cere configuratii personalizate?

Da, iti putem adapta configuratia de CPU, RAM si stocare in functie de necesitati — scrie-ne cerinta.


4. Pot schimba sistemul de operare?

Da, oferim mai multe sisteme de operare Linux si Windows la cerere.

Gazduire Web [4 intrebari]
1. Ce este gazduirea web (shared hosting)?

Gazduirea web presupune stocarea fisierelor site-ului tau pe serverele noastre, astfel incat acesta sa fie accesibil online 24/7. Planurile noastre folosesc stocare SSD si panou de control cPanel.


2. Gazduirea include si conturi de email?

Da, toate planurile de gazduire includ conturi de email pe domeniul tau, administrabile direct din cPanel.


3. Pot face upgrade la planul meu de gazduire?

Da, poti trece oricand la un plan superior direct din contul de client, fara intreruperea site-ului.


4. Oferiti garantie de returnare a banilor?

Detaliile despre garantie si politica de rambursare sunt disponibile in Termenii si Conditiile noastre.

VPS Cloud [4 intrebari]
1. Serverele VPS au politica de backup?

Da, efectuam backup-uri periodice pentru toate serverele VPS, pentru siguranta datelor tale.


2. Care sunt avantajele unui VPS Cloud?

Resurse dedicate (CPU, RAM, stocare), acces root complet si posibilitatea de a scala oricand, fara migrare de date.


3. Gazduirea de email este inclusa?

Cu acces root complet, poti instala propriul server de email sau folosi solutii externe, dupa preferinta.


4. Ce tip de suport oferiti?

Suport tehnic 24/7 prin tichet, pentru orice problema legata de server.

Domenii [2 intrebari]
1. Cum inregistrez un domeniu nou?

Cauta domeniul dorit din pagina de Domenii si finalizeaza comanda direct in contul de client.


2. Pot transfera un domeniu existent la voi?

Da, transferul de domenii este posibil — contacteaza-ne pentru pasii exacti in functie de extensie.
