# Jurnal de partide

Datele reale ale utilizatorului — sursa cu cea mai mare prioritate. O intrare per partidă, cele noi sus.

## Format

```
### AAAA-LL-ZZ — <nume apă / județ>
- Tip apă: comercială / lac natural / râu / Dunăre / acumulare
- Temp. apă: __°C (tendință: ↑/↓/stabil) · pH: __ (sau necunoscut) · Adâncime/fund: __
- Vreme: presiune, vânt (direcție), front
- Nadă: boilies (bază, aromă, mm), cantitate totală, + alte (pelete, particule, PVA)
- Cârlig: tip, mm, culoare, montură
- Rezultat: specie, nr. capturi, greutăți, ore ale trăsăturilor
- Pește mărunt pe nadă: da/nu
- Concluzie / ce aș schimba:
- Reguli din knowledge.md confirmate/contrazise:
```
